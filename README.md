# MRU

**MRU** is an essential library mod designed to streamline and enhance the development process for my mods. MRU significantly reduces the time and effort needed to create and maintain mods across multiple versions of Minecraft.

Since 1.0.30, MRU now provides multiversioned utilities for Cassian's mods, including reusable logic for Immersive Overlays and Immersive Minimaps. Eventually, this should allow many of these mods to not need platform specific code, cutting down maintenance work.
